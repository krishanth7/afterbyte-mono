# Code of conduct

## Our commitment

Everyone should be able to contribute regardless of experience, disability, age, gender, identity, nationality, race, religion, or background. Discuss the work with respect and make participation practical for people using different tools and assistive technologies.

## Expected conduct

Give specific constructive feedback, accept correction, credit others' work, respect boundaries, and explain design decisions. Avoid personal attacks and gatekeeping. Make room for questions and alternative approaches.

## Unacceptable conduct

Harassment, threats, discriminatory comments, sexual harassment, doxxing, impersonation, persistent unwanted contact, and publishing private information are not acceptable.

## Scope

This policy applies to repository issues, pull requests, reviews, and project spaces maintained by the project. It also applies when someone explicitly represents the project elsewhere.

## Reporting

For non-sensitive moderation concerns, contact the maintainer through a public project issue without naming victims or publishing private details. For a sensitive report, first request a private contact channel using a minimal public message; no dedicated confidential channel is currently advertised. Security vulnerabilities follow SECURITY.md.

## Enforcement

The maintainer reviews available context and may request an edit, issue a warning, remove content, temporarily restrict participation, or ban participation for serious or repeated violations. Decisions should be proportionate and protect affected people. Reporters and affected participants should not face retaliation.

An appeal may request reconsideration with new context through the same established contact channel. No guaranteed response time or independent appeals body is claimed.
