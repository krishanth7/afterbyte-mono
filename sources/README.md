# Font sources

- [afterbyte-mono/vectors.json](afterbyte-mono/vectors.json): original 196-character centerline core, regenerated by `tools/draw_afterbyte_vector.py`.
- [afterbyte-mono/coverage-v4.json](afterbyte-mono/coverage-v4.json): explicit 1704-character mapping and origin contract.
- [afterbyte-mono/coverage-v5.json](afterbyte-mono/coverage-v5.json): explicit 2499-character mapping and origin contract.
- [upstream](upstream): pinned, attributed OFL Noto expansion source, original license and checksum provenance.

`tools/build_core.py` compiles the original core; `tools/build_afterbyte.py` assembles the versioned expansions, Braille, technical operators and mathematical styles. `tools/prepare_expansion.py` can recreate the licensed static source from a pinned, hash-checked upstream download. Ordinary builds use the committed subset and need no network access.

The earlier `afterbyte-mono/pixels.json` and `tools/draw_afterbyte.py` are historical pixel-study sources. See [provenance](../docs/PROVENANCE.md), [design](../docs/DESIGN.md) and the [OFL](../OFL.txt).
